# 汇丰美元管家（iOS 可安装的 PWA）

一个装在 iPhone 主屏幕上的小应用：**每天上午 10 点提醒你，把汇丰银行两个美元账户的余额填一次**——「储蓄美元账户」和「投资美元账户」，App 自动算出合计、画趋势图、留历史记录，并支持导出 CSV / 备份 JSON。

- 纯网页（PWA），不需要上架 App Store，不需要开发者账号，也不需要 Mac。
- 数据只存在你的手机本地（localStorage），**不上传任何服务器**，不碰汇丰账号密码。
- 支持 iPhone / iPad / Android，浅色深色模式自适应。

## 一、功能一览

| 功能 | 说明 |
| --- | --- |
| 每日记录 | 两个输入框：储蓄美元账户、投资美元账户；实时显示合计 |
| 补记 / 修改 | 日期可改（不能选未来），历史记录点一下即可载入修改 |
| 汇总卡片 | 最新总额、较上次增减（金额 + 百分比）、累计记录天数 |
| 趋势图 | 7 天 / 30 天 / 90 天 / 全部；合计、储蓄、投资三条线，点图例可单独显示/隐藏 |
| 历史记录 | 按天倒序，显示当天合计与两个账户拆分、较前一天的变化、备注 |
| 导出 | CSV（Excel 可直接打开，含 UTF-8 BOM 不乱码）、JSON 备份 |
| 恢复 | 支持恢复 JSON 备份，同一天以备份数据为准 |
| 离线可用 | 首次打开后缓存到本机，没网也能记录和查看 |
| 提醒 | 用 iOS「快捷指令」自动化，每天 10:00 自动打开本页 |

## 二、部署（三选一，都免费）

App 是一个纯静态网站，把 `index.html` 所在目录整个传上去即可。**必须用 HTTPS**，否则 iPhone 无法「添加到主屏幕」、也无法离线缓存。

### 方案 A：GitHub Pages（推荐，长期稳定）

1. 注册/登录 GitHub，新建一个仓库，例如 `hsbc-usd-tracker`（Public 即可）。
2. 把本目录下的这些文件上传到仓库根目录：
   `index.html`、`styles.css`、`core.js`、`app.js`、`manifest.webmanifest`、`sw.js`、`icons/` 文件夹。
   （网页上「Add file → Upload files」直接拖进去即可。）
3. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存。
4. 等 1~2 分钟，访问 `https://你的用户名.github.io/hsbc-usd-tracker/`。
   > 如果仓库名不是 `用户名.github.io`，网址后面一定要带仓库名和斜杠。

### 方案 B：Cloudflare Pages（拖拽最快）

1. 打开 <https://pages.cloudflare.com/>，登录后选 `Create a project` → `Direct Upload`。
2. 把本目录（含 `icons` 文件夹）拖进去，点部署。
3. 拿到 `https://xxx.pages.dev` 网址即可。

### 方案 C：本地预览（只在自己电脑上看效果）

在项目目录执行（需要 Python）：

```bash
python -m http.server 8765
```

然后浏览器打开 `http://127.0.0.1:8765/`。注意 `file://` 直接双击打开不行：Service Worker 和部分功能会失效。

## 三、装到 iPhone 主屏幕

1. 用 **Safari**（必须是 Safari，微信/Chrome 内置浏览器不行）打开上面的网址。
2. 点底部「分享」按钮 → 往下找 → **添加到主屏幕** → 右上角「添加」。
3. 主屏幕会出现红色 `$` 图标，点开就是全屏 App，没有地址栏。

> 第一次打开时，页面顶部会出现一条安装提示，照着做即可；点 ✕ 可关闭，不再出现。

## 四、设置每天 10:00 提醒（重点）

iPhone 不允许网页自己定时弹通知，正确做法是用系统自带的「快捷指令」自动化。**设置一次，以后每天 10 点自动打开填写页。**

1. 打开「快捷指令」App → 底部「**自动化**」→ 右上角「**+**」（没有的话先随便建一个快捷指令再进自动化）。
2. 选「**特定时间**」→ 时间设为 **10:00**，重复选「**每天**」。
3. 下一步，搜索并添加操作「**打开 URL**」，填入你的 App 网址（例如 `https://你的用户名.github.io/hsbc-usd-tracker/`）。
   - 如果已经添加到主屏幕，也可以在「打开 App」里选择「汇丰美元管家」。
4. **关闭「运行前询问」**（否则每天会先弹一个确认框，还得点一下）。
5. 保存。到点后手机会自动跳到填写页，填两个数字 → 点「保存记录」，10 秒钟搞定。

小技巧：
- 想更省事，可以在「打开 URL」后面再加一个「**显示通知**」操作，写「该记美元余额啦」，这样即使不点开也能看到提醒。
- 如果不想自动跳转，只想收提醒：把第 3 步换成「显示通知」或「显示提醒」，通知里点一下也能打开。
- 想改时间：自动化列表里长按该自动化 → 编辑。

## 五、每天怎么用

1. 打开 App（或等 10:00 自动打开）。
2. 在「储蓄美元账户」「投资美元账户」里填当天余额（支持 `1,234.56`、`$1234.56` 这种写法，最多两位小数；留空按 0 算，但两个都空不能保存）。
3. 合计会自动算好，确认后点「**保存记录**」。
4. 想补记以前某天：把「日期」改成那一天，填数字保存即可；已有记录会自动带出来，点「更新记录」覆盖，或点「删除这一天的记录」删掉。
5. 「备注」可以写「工资入账」「转出生活费」之类，方便回看。

填写小贴士：
- 储蓄账户 = 汇丰的美元储蓄/往来账户余额；投资账户 = 投资户口里的美元市值/现金余额。具体以你 App 里看到的数字为准，两个加起来就是「美元总资产」。
- 建议固定在 10:00 记，口径一致，趋势图才有可比性。

## 六、数据与备份（务必看）

- 数据保存在**本机浏览器的 localStorage**，不会上传，也不会同步到 iCloud。
- 清除 Safari 数据、删除主屏幕图标、换手机、重装系统都可能**丢数据**，所以：
  - 建议每周点一次「**备份 JSON**」，文件会存到「文件」App 的下载目录，可再传到 iCloud 网盘。
  - 换手机后，在新手机打开 App → 「**恢复备份**」→ 选择那个 JSON 文件即可。
  - 「导出 CSV」用于 Excel/Numbers 做进一步统计，不能用来恢复。
- 「恢复备份」遇到同一天已有记录时，**以备份文件里的数据为准**；其他日期会合并保留。
- 「清空数据」会删掉全部记录，操作前会二次确认。

隐私说明：本 App 不联网、不收集任何信息、不要求汇丰账号密码，也不会自动读取银行数据——所有数字都是你手动填的。部署在 GitHub Pages / Cloudflare Pages 上时，托管平台可能记录访问日志（IP、时间），不涉及你的余额数据。

## 七、常见问题

**Q：能不能自动读取汇丰账户余额？**
不能。汇丰没有面向个人的公开 API，读取余额需要登录网银/App 授权，任何让你输入网银密码的第三方工具都有风险。手动填两个数字是最安全的做法。

**Q：10 点提醒没响 / 没自动打开？**
检查「快捷指令 → 自动化」里那条自动化是否开启、时间是否为 10:00、是否关闭了「运行前询问」；iOS 的自动化在低电量模式或专注模式下可能延后。另外确认 App 网址能在 Safari 里正常打开（HTTPS）。

**Q：添加到主屏幕后图标是白底或旧图标？**
iOS 有时会缓存图标。删掉主屏幕图标，重新用 Safari 打开网址再添加一次即可。

**Q：更新了网页，App 里还是旧版本？**
Service Worker 会缓存页面。把 App 彻底上滑关掉再打开一次；仍不行就等一两分钟再开。开发者更新代码时，把 `sw.js` 里的 `CACHE_VERSION` 改成 `v2`、`v3`…… 可强制所有设备更新。

**Q：能同时在 iPhone 和 iPad 上用吗？**
可以，但两边数据各自独立（本地存储不互通）。可以用「备份 JSON → 恢复备份」手动同步。

**Q：会花很多电/流量吗？**
不会。页面只有几十 KB，首次加载后离线可用。

**Q：数据会不会被网页看到？**
不会。数据只存在你手机浏览器的 localStorage 里，网页代码没有上传逻辑；同域名下的其他页面理论上能读到同源 localStorage，所以建议用自己专属的部署地址（自己的 GitHub Pages / Cloudflare Pages）。

## 八、文件结构与开发

```
hsbc-usd-tracker/
├── index.html              # 页面结构
├── styles.css              # 样式（iOS 风格，浅色/深色）
├── core.js                 # 纯逻辑：金额解析、日期、汇总、CSV、备份（浏览器/Node 通用）
├── app.js                  # 交互：表单、统计、SVG 趋势图、导入导出、弹窗
├── manifest.webmanifest    # PWA 清单
├── sw.js                   # Service Worker（离线缓存）
├── icons/                  # 图标 180/192/512/maskable
├── make_icons.py           # 用 Pillow 重新生成图标
├── test/
│   ├── core.test.js        # core.js 单元测试（node --test）
│   └── shoot.js            # 用 CDP 截图 + 端到端验证（需要本地起服务 + 无头 Edge）
└── README.md
```

本地测试：

```bash
# 逻辑单元测试
node --test test/core.test.js

# 截图与端到端验证（另开两个终端）
python -m http.server 8765
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --remote-debugging-port=9222 --user-data-dir=%TEMP%\edge-pwa about:blank
node test/shoot.js
```

想改配色：编辑 `styles.css` 顶部的 `:root` 变量（`--red` 等）。想改应用名：改 `index.html` 的 `<title>`、顶栏文字和 `manifest.webmanifest` 里的 `name` / `short_name`。
